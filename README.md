## Uander Santos

Sistemas, anúncios e processos para assistência técnica — e para quem vive de
publicar conteúdo. Construo as ferramentas que uso todo dia na operação, e
depois transformo em produto.

### Ativa — a suíte

| | |
|---|---|
| **[ATIVAVID](https://ativavid.com)** | Edição de vídeo com IA que roda na **sua máquina**. Corta, legenda, escreve a manchete, escolhe a trilha e entrega pronto para postar — sem subir as gravações para servidor nenhum. Aplicativo de desktop com atualização automática, motor de render próprio, 85 estilos de legenda e 55 de manchete. |
| **Ativa CRM** | CRM e área de membros para operações de serviço. |
| **Ativa Dash** | Dashboards de marketing, vendas e integrações para agências e gestores de tráfego. |
| **Ativa Fix** | Ordens de serviço e diagnóstico para assistência técnica. |
| **Ativa Prompt** | Biblioteca de prompts da operação. |

### Outras plataformas

- **Matti Academy** — formação online com área de membros (cursos, aulas em
  vídeo, progresso) e painel administrativo. Supabase: Postgres, Auth e Edge
  Functions.
- Sistemas sob medida para clientes — CRM, captação de leads e painel,
  em produção.

### Prime Camp

Assistência técnica de celulares em Campinas/SP. É onde tudo acima é testado
antes de virar produto.
